# Ocean Tower Defence

幼児向けの海テーマタワーディフェンス。TypeScript + Vite + HTML5 Canvas で作成。外部ゲームライブラリなし・フルスクラッチ。スマートフォン対応。

## 起動

```bash
npm install   # 初回のみ
npm run dev   # http://localhost:5173 で開く
```

## ゲームの目標

サメたちがゴール（マップ右端の卵）に到達するのを防ぐ。サメが卵に着くたびに **卵が 1 つ減る**。**卵がすべてなくなるとゲームオーバー**。全 5 Wave を乗り越えれば **CLEAR!**

---

## ゲームの流れ

```
ゲーム開始
  ↓
【ビルドフェーズ】ひび割れ卵を使ってタコ・珊瑚を設置
  ↓
▶ ボタンで Wave 開始
  ↓
【Waveフェーズ】サメが経路を通って卵を狙う
  ↓
Wave クリア → ひび割れ卵を獲得（守れた卵の数だけ）
  ↓
【卵置きフェーズ】次のゴール場所をタップして選ぶ（Wave 1以降）
  ↓
【ビルドフェーズ】タコ・珊瑚を追加設置
  ↓
次の Wave へ …（Wave 5 クリアで CLEAR!）
```

---

## 操作方法

| 操作 | 内容 |
|---|---|
| 白い点を **2秒長押し** | タコを設置（ひび割れ卵 1個） |
| オレンジの点を **2秒長押し** | 珊瑚を設置（ひび割れ卵 1個） |
| 右端のキラキラした場所をタップ | 次の卵の場所を選ぶ（卵置きフェーズのみ） |
| ▶ ボタン | 次のウェーブを開始 |
| ⏸ ボタン | 一時停止 / 再開 |
| ↩ ボタン | ゲームをリスタート |

長押し中は **半透明プレビュー＋白い進捗リング＋コスト（ひび割れ卵アイコン）** が表示される。

## 資源システム

### 卵（通常の卵）— HP

- 初期: **7個**（マップ右端のゴールに表示される）
- サメがゴールに到達するたびに **1個減る**
- ウェーブクリア後も消費しない（HPとして残り続ける）
- 0になると **ゲームオーバー**

### ひび割れ卵 — 建設資源

- 初期: **3個**
- **ウェーブクリア時**に「守れた卵の数（残り HP）」だけ獲得
- タコ・珊瑚の設置コストは **各 1個**
- 上限なし

---

## 配置できるもの

### タコ（攻撃タワー）

- **コスト**: ひび割れ卵 1個
- **射程**: 150px、**ダメージ**: 20、**連射**: 1/s
- 射程内の最も近いサメへ自動で**墨を吐いて**攻撃
- マップ上に **10箇所**（白い点）

### 珊瑚（壁）

- **コスト**: ひび割れ卵 1個
- サメの通り道（PATH タイル）に設置し、通過するサメを **速度 35% に減速**
- 各経路に **1箇所**ずつ（オレンジの点）

---

## マップ（5本の経路）

Wave が進むごとにプレイヤーが選んだゴール場所が増え、経路も増える。

| 経路 | 主要行 | 開放タイミング |
|---|---|---|
| 経路 1 | row 1 | ゲーム開始時（固定） |
| 経路 2〜5 | row 3 / 5 / 7 / 9 | Wave クリア後に自分で選択 |

各経路は横断 S 字形。全経路のゴール（右端）に卵クラスターが表示される。

---

## 敵（サメ）

| 種類 | 色 | 速度 | HP | 出現ウェーブ |
|---|---|---|---|---|
| 小サメ | 青 | 180 px/s | 60 | Wave 1〜 |
| 中サメ | 黄 | 120 px/s | 200 | Wave 2〜 |
| **ボスサメ** | **赤** | 80 px/s | **800** | **Wave 5 のみ** |

すべてのサメは **怒り眉・牙・三日月目** のデザイン。各ウェーブで有効な経路からランダムに出現。

---

## ウェーブ構成（全 5 Wave）

| Wave | 内容 | 有効経路数 |
|---|---|---|
| 1 | 小 ×10 | 1本 |
| 2 | 小 ×10 + 中 ×4 | 2本（1本目＋選択した1本） |
| 3 | 小 ×6 + 中 ×10 | 3本 |
| 4 | 中 ×12 | 4本 |
| 5 | 小 ×6 + 中 ×4 + **ボス ×2** | 5本 |

各ウェーブは **▶ ボタン**を押すまで始まらない。卵置きフェーズ中はボタンが無効。

## HUD（画面上部バー）

```
🥚×7  [ひび割れ卵]×3  🦈 1/5  [小サメ]×10 [中サメ]×4
```

- **🥚×N**: 残り卵（HP）
- **[ひび割れ卵]×N**: 建設資源
- **🦈 N/5**: 現在のウェーブ
- **右側**: 次ウェーブの敵予告（種類・数）

---

## エフェクト

- **着弾**: 紫の墨しぶきパーティクル
- **撃破**: 暗紫の墨爆発パーティクル
- **珊瑚ゾーン通過**: サメが目に見えて遅くなる
- **被弾フラッシュ**: サメがゴールに到達すると画面が赤く点滅
- **卵置きフェーズ**: 未開放ゴールが黄色にパルス点灯、画面下部にガイド表示
